# Manish Kumar Sharma — Academic Website

This is a self-contained static academic website.

## Files
- index.html — website content
- styles.css — responsive design
- script.js — mobile menu and current year

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `manish-sharma-website`.
2. Upload these files to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. GitHub will provide the public website address.

## Before publishing
- Replace the portrait placeholder with a professional photograph if desired.
- Add DOI links to publications.
- Add a CV PDF download.
- Add project/field photographs.
- Consider adding a Google Scholar/GitHub profile and a custom domain later.

The public version intentionally does not display the phone number from the CV.
